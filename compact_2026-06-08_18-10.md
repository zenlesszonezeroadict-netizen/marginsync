## Project overview
MarginSync is a Shopify supplier price-list repricing Micro-SaaS built by a solo developer
on a $0 budget. It allows Shopify merchants to upload supplier CSV/XLSX files, auto-match
supplier SKUs to Shopify variants, apply margin-aware pricing rules, preview a price diff
table, and one-click push updated prices to Shopify. Stack: Next.js 16.2.7 App Router +
Supabase (Auth + Postgres + Storage) + Stripe Checkout + Shopify Admin API + Vercel Hobby.

- AES-256-GCM encryption (TOKEN_ENCRYPTION_KEY env var, 64-char hex) used for Shopify token — not Supabase Vault (too complex for MVP)
- Free-tier quota: 3 non-failed runs; Pro = unlimited
- Mock catalog (80 items) used as fallback when no live sku_mappings exist; replaced in Issue #11 by live catalog

- `PricingRule` cast via `as unknown as Json` for DB writes — zero `any` types used throughout
- Explicit `if (membership)` blocks (not ternary) in server components to avoid TypeScript `never` inference
- `createAdminClient()` (service role) for server-side admin ops — never exposed to browser
