## Project overview
MarginSync is a Shopify supplier price-list repricing Micro-SaaS. Merchants upload supplier
CSV/XLSX files, auto-match supplier SKUs to Shopify variants, apply margin-aware pricing
rules, preview a price diff table, and one-click push updated prices to Shopify. Stack:
Next.js 16.2.7 App Router + Supabase (Auth + Postgres + Storage) + Shopify App Billing +
Shopify Admin API + Vercel Hobby. **Status: fully deployed, E2E verified, App Store ready.**

Live URL: `https://marginsync-wheat.vercel.app`  
Test store: `marginsync-test-shop.myshopify.com`

## Important facts to remember

**Project location:** `C:\Users\hendr\OneDrive\Desktop\marginsync`

**Run state machine:** `pending → parsed → previewed → syncing → completed | failed`

**DB schema:** 6 tables (`organizations`, `profiles`, `organization_members`, `shopify_connections`, `sku_mappings`, `reprice_runs` → cascades `reprice_run_items`). Migrations in `supabase/migrations/`.

**RLS pattern:** All org-scoped queries use `auth_org_ids()` (SECURITY DEFINER). Admin client bypasses RLS for server-side writes.

**Encryption:** `TOKEN_ENCRYPTION_KEY` = 32 bytes = 64 hex chars. NEVER rotate after first deploy — rotates break all existing encrypted tokens in `shopify_connections.access_token_encrypted`.

**HMAC distinction:** OAuth callback → `.digest('hex')`. Webhooks → `.digest('base64')`. Two different verifiers; do not share.

**Free quota:** 3 non-failed runs. Gate in `POST /api/runs` → HTTP 402. `failed` status runs do NOT count toward quota.

**Live vs mock catalog:** `loadLiveCatalog()` returns `[]` if no `sku_mappings` exist → `matchSKUs` falls back to `MOCK_CATALOG` automatically.

**Billing:** Shopify App Billing only (Stripe dropped — Indonesia cross-border restrictions). Free: 3 runs/mo. Pro: $19/mo.

**Shopify Partner Dashboard config:**
- App URL: `https://marginsync-wheat.vercel.app`
- Allowed Redirect: `https://marginsync-wheat.vercel.app/api/shopify/callback`
- GDPR webhooks: `/api/shopify/webhooks/customers-data-request`, `/api/shopify/webhooks/customers-redact`, `/api/shopify/webhooks/shop-redact`

**Rollback route:** `POST /api/runs/{runId}/rollback` — one-shot (requires `status='completed'` AND `rolled_back_at IS NULL`). Returns 409 on second call.

**`shop/redact` deletion order:** `reprice_runs` (cascades `reprice_run_items`) → `sku_mappings` → `shopify_connections`. Does NOT delete `organizations`/`profiles` — account intact for re-install.
